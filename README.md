# LoL Quiz Party

친구들과 링크로 접속해서 동시에 푸는 실시간 League of Legends 퀴즈 사이트입니다.

## 기능

- 방장이 방 생성 → 5자리 방 코드/초대 링크 생성
- 친구들이 닉네임 + 링크/방 코드로 입장
- 방장이 문제, 보기 4개, 정답, 제한시간 직접 편집
- 모든 참가자에게 같은 문제 실시간 전송
- 빠르게 맞힐수록 500~1000점 획득
- 답변 진행 인원 표시
- 문제마다 정답 공개 + 실시간 순위
- 최종 순위 / 다시 한 판
- 모바일 대응

## 로컬 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.

같은 Wi-Fi의 친구에게 테스트용으로 보여주려면 PC의 로컬 IP와 3000 포트를 사용해야 하지만,
인터넷의 친구들이 링크로 접속하려면 아래처럼 서버에 배포해야 합니다.

## 배포

이 프로젝트는 일반 Node.js 서버 + Socket.IO를 사용합니다.
Node.js 웹 서비스를 지원하고 WebSocket 연결을 유지할 수 있는 호스팅에 올리면 됩니다.

필수 실행 명령:

- Build: `npm install`
- Start: `npm start`
- Port: 호스팅이 넣어주는 `PORT` 환경변수를 서버가 자동 사용

GitHub에 이 폴더를 올린 뒤 Node.js 웹서비스로 배포하면 생성된 공개 URL을 친구들에게 공유할 수 있습니다.

## 주의

현재 버전은 방/점수를 서버 메모리에 저장하는 MVP입니다.
서버가 재시작되면 진행 중인 방은 사라집니다. 친구들과 즉석 퀴즈를 하기에는 충분하지만,
회원가입, 문제 영구 저장, 전적 기록이 필요하면 DB(Supabase/PostgreSQL 등)를 추가하면 됩니다.
