# 한국어 아케이드: 설계와 검증

기존 Express/Socket.IO 게임센터에 `/korean/` 카테고리와 6개의 게임 카드를 추가한다. 기존 6개 게임의 이벤트·화면·데이터는 유지한다. 같은 HTTP 서버와 Socket.IO 인스턴스를 사용하고 한국어용 `/korean` namespace에서 세션을 관리한다. Render용 서버를 Cloudflare용 서버로 바꾸지 않는다.

## 기출 확인 범위와 출처

- [TOPIK 공식 사이트](https://www.topik.go.kr/): 공개 자료 확인 경로. 이번 환경에서는 본문을 가져오지 못했다.
- [제64회 TOPIK II 읽기 공개 문제지 사본](https://trilingual.jp/wp-content/uploads/TOPIK/64_TOPIK2/64_TOPIK2_%E5%95%8F%E9%A1%8C%EF%BC%88%E8%AA%AD%E8%A7%A3%EF%BC%89.pdf)
- [제83회 TOPIK II 읽기 공개 문제지 사본](https://trilingual.jp/wp-content/uploads/TOPIK/83_TOPIK2/83_TOPIK2_%E5%95%8F%E9%A1%8C%EF%BC%88%E8%AA%AD%E8%A7%A3%EF%BC%89.pdf)

후자의 두 파일은 공식 도메인이 아닌 외부 사이트에 보관된 시험지 사본이다. PDF를 내려받아 이미지로 렌더링해 확인했다. 확인 범위: 두 회차 모두 PDF 10·16·22쪽, 추가로 83회 PDF 5쪽. 전체 문항이나 최신 회차 전체를 분석했다고 주장하지 않는다. 문제지나 이미지 파일은 저장소에 포함하지 않는다.

관찰: 두 회차의 16–18번은 짧은 설명문의 빈칸을 문맥으로 판단한다. 30–31번은 여러 문장에 분산된 근거를 연결해야 한다. 42–43번은 길어진 서사에서 심정과 사실 관계를 나누어 판단한다. 83회 초반에는 문법 빈칸과 유사 의미 판별이 나온다. 표면 단어 일치만으로 고르면 틀릴 수 있어, 오답을 인과 방향 역전·과도한 일반화·부분 정보·태도 오해로 설계했다.

설계 판단: 짧은 문맥은 조준 게임, 문법 비교는 2상황 배치로 변환하기 좋다. 긴 독해는 짧은 타이머와 잘 맞지 않으므로 독해 전용 장기 미션은 추후 확장한다. 순서 조립은 요청된 TOPIK 유형에 따른 자체 설계이며, 위 표본만으로 배열 유형의 회차별 빈도를 추정하지 않았다.

## 문항과 난이도

현재 오리지널 60문항: 문맥·문법·어휘·순서·수정 각 12개. 기본 LEVEL 4는 내부 태그 4–5만 사용한다. LEVEL 1은 태그 1–2, LEVEL 2는 2–3, LEVEL 3은 3–4, LEVEL 5는 5만 사용한다. 문항 수가 적은 하위 레벨은 짧은 판이 된다. 부족한 문제를 복제해 미션 수를 채우지 않는다. 정확한 미션 수는 시작 시 표시된다. 보스전은 5종을 순환하고 5/10/20/30개 중 이용 가능한 수만큼 구성한다.

정답 위치와 카드 순서는 서버에서 무작위화한다. Solo는 브라우저의 이전 문항 ID로 미경험 문항을 우선한다. 해설에서 정답·오답 차이·관련 표현·일본어 설명을 제공한다. 일본어 정답 설명은 해설에서 버튼을 열어야 보인다. 문제 화면의 일본어는 조작 도움말뿐이다. 타이핑은 NFC 정규화·앞뒤 공백·마지막 문장부호를 허용하고 맞춤법에 중요한 내부 띄어쓰기는 유지한다. 허용 답안이 복수인 문항에는 `accepted`를 쓴다.

등급 태그는 제작자 추정이며 실제 학습자 데이터로 보정되지 않았다. 읽기 중심의 짧은 게임으로 공식 TOPIK 급수를 예측하는 것은 부정확하므로 B/A/S/S+ 게임 랭크와 영역별 정확도만 표시한다. 요청서의 예시처럼 TOPIK 5급 상위권이라고 단정하지 않는다. 정식 실전 챌린지·긴 독해·말하기 게임은 아직 구현하지 않았다.

## 플레이와 기록

- Solo: 즉시 시작. 닉네임 없이 기본 이름으로 가능.
- VS: 2–8명, 동일 문제·서버 마감 시간. 점수와 콤보로 경쟁. 생존전/보스전은 개인 HP 3, 소진 후 관전.
- CO-OP: 2–8명, 대화하며 각자 제출. 팀 HP 5, 한 명 이상 오답이면 라운드당 -1. HP 0이면 끝. 한 명이라도 정답이면 보스 HP -1. 기본 음성 통화는 내장하지 않음.
- 정확도 중심 점수: 정답 100점, 연속 정답 보너스 최대 100점. 빨리 누른 뒤 틀리면 점수 없음.
- 문항별 35–65초. 해설은 전원 준비 완료 또는 60초 후 이동. 연결된 사람이 없으면 다음 라운드를 시작하지 않음.
- localStorage: 최근 1,500개 문항 기록·100개 판 기록, 최고/오늘/최근 점수, 영역별 정확도, 오답. 복습은 해당 문항만 선택. 데이터 저장 불가 시 게임을 계속하며 안내.

## 안정성

- 서버가 점수·정답·마감 시간을 결정. 정답·해설·일본어 정답 도움말은 제출 전 전송하지 않음.
- 모든 제출/준비에 라운드 키를 확인해 이전 라운드의 늦은 요청 무시.
- 중복 제출은 최초 1회만 인정. 동일 라운드 이중 채점 방지.
- 30초 재접속 유예와 서버 발급 비밀 토큰. 제출 여부·라운드·남은 시간 복원. 이미 연결된 동일 세션은 이전 탭을 종료.
- 재접속한 클라이언트에도 최신 서버 상태 제공. 화면 타이머는 로컬 monotonic clock으로 표시.
- 중간 이탈 시 연결된 참가자 기준으로 완료 판정, 호스트 완전 이탈 시 방장 이전. 방은 최대 2시간 유지.
- 무효 세션·참가하지 않은 사용자의 요청·잘못된 데이터 무시. 참가 중인 사용자의 중복 방 생성 방지.
- 텍스트는 `textContent`로 출력. 학습 데이터는 서버에 영구 저장하지 않으며, 현재 방 상태만 메모리에 유지.

## 검증

`npm test`: Node 테스트 + 실제 Socket.IO 클라이언트 + jsdom 화면 조작 테스트. 전 게임 완주, 시간 초과, 전원 완료, 중복/과거 요청, 재접속, 방장 이전, HP 종료, 학습 기록 중복 방지, 정답 비노출, 다섯 입력 방식, 기존 카드 보존을 확인한다. 9개 테스트가 통과했다. 실제 서버를 별도 프로세스로 실행하여 `/health`, `/`, `/korean/`, JS/CSS 응답과 기존 원신 퀴즈 1라운드 완료도 확인했다.

실제 브라우저의 화면 배치·스마트폰 한국어 IME·Render 운영 환경 검증은 별도다. DOM 테스트를 시각적 브라우저 검증이라고 표현하지 않는다. 원격 운영 사이트의 실시간 응답은 이번 환경의 웹 열기에서 확인되지 않았다.
